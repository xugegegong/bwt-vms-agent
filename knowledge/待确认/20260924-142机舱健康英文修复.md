## 内容

**一、原条目写错了根因。** 原条目 5 说英文空白是 `component_name_en` / `device_name_en` 为空。实测发现这只是表象，**真正的根因是第三层**：`tab_engine_param_menu_mimic_config` 表里英文（`language=1`）的机舱健康（`menu_type='2'`）配置**一条都没有**——组态图和绑点全在这套记录里，没有它整页就是空白。只填 `component_name_en` 修不好。

**二、术语表需要权威确认。** 我为 15 个部件拟了英文名，这是 AI 拟的，**需要组长确认后才能作为后续所有船的标准**：

| component_key | 中文 | 本船使用 |
|---|---|---|
| 000000 | 主机 | Main Engine |
| 0001 | 主机本体 | Main Engine Body |
| 0002 | 主机SCR系统 | Main Engine SCR System |
| 0005 | 主机润滑系统 | ME Lubrication System |
| 010000 | 1号发电机 | No.1 Generator |
| 0101 | 1号发电机本体 | No.1 Generator Body |
| 0102 | 1号发电机SCR系统 | No.1 Generator SCR System |
| 020000/030000 | 2号/3号发电机 | No.2 / No.3 Generator |
| 040000 | 轴带发电机 | Shaft Generator |
| 0401 | 轴带发电机本体 | Shaft Generator Body |
| 应急发电机 | 应急发电机 | Emergency Generator |

**存疑点**：主机润滑系统用了 `ME Lubrication System`（缩写 ME），但主机本体用的是全称 `Main Engine Body`，**风格不统一**。是统一用缩写（M.E.）还是全称？由组长定。
